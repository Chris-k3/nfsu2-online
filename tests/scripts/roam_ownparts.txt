# The player's own car's shop parts from the shared packs (rims, spoiler,
# exhaust tips, ...) through free roam among friends, crib visits and career
# races.  From a career save the bot loads free roam; "mp solids" says, for
# each of those parts, whether the car's render info has its model and that
# model its solid (drawn), and which of the streamer's packs list it.  Then
# VISITS times the crib (the front end and back), then NFSU2_CAREER_BOT_RACES
# races, back in free roam between them.  Two pages with the same save in
# one room see each other's car with exactly the player's parts.
#   node web/tools/roam-crowd.mjs --base <server> --n 32 --cars all --room <r>
#   NFSU2_SAVE_SEED=<a career save> node web/tools/run-suite.mjs --base <server>
#        --script roam_ownparts.txt --marker "quit at guest frame" --net <name>
#        --env NFSU2_ROAM=1 --env NFSU2_ROAM_WEBTEST=vlan --env NFSU2_ROAM_ROOM=<r>
#        --env ROAM_CROWD_CARS=32 --env VISITS=3 --env NFSU2_CAREER_BOT_RACES=3 --timeout-scale 3
