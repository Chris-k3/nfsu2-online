# Pad-only career: new profile (default name) -> Career -> Start New Career
# -> SMS -> free roam; drive with the triggers/stick, then the in-race D-pad
# actions of the game's layout: Left = World Map, Right = Read SMS,
# Down = Career Statistics (Up = Engage needs an event marker).
0     pad connect
+0    tappaduntil START MC_Background.fng 120 4000
+120  tappad DLEFT                                   # create a profile: Yes
+30   tappad A
+300  tappad A                                       # name field (first Enter is ignored)
+300  tappad A                                       # accept "NAME"
+240  tappad DLEFT                                   # save it: Yes
+60   tappad A
+400  tappad A                                       # Save complete
+0    waitfng GarageMain.fng 3000
+300  tappad DLEFT                                   # career icon
+60   tappad A                                       # Career
+300  tappad A                                       # Start New Career
+0    waitfng UI_EngageMessageDialog.fng 6000
+300  dump sms
+0    tappad A                                       # SMS: Continue
+0    waitfng HUD_SingleRace.fng 3000
+1200 log --- free roam: drive ---
+0    trigger RT 1
+300  axis LX 0.4
+120  axis LX 0
+240  dump roam
+0    trigger RT 0
+0    trigger LT 1
+300  trigger LT 0
+60   log --- D-pad Left: World Map ---
+0    tappad DLEFT
+240  dump world_map
+0    tappad B
+240  dump after_map
+0    log --- D-pad Right: Read SMS ---
+0    tappad DRIGHT
+240  dump sms_read
+0    tappad B
+240  log --- D-pad Down: Career Statistics ---
+0    tappad DDOWN
+240  dump career_stats
+0    tappad B
+240  dump back_to_roam
+60   quit
