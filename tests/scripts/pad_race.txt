# Pad-only Quick Race, then every in-race control from the pad: analog
# steering at partial deflections, analog throttle/brake on the triggers,
# e-brake, NOS, camera, look back, pause.  "@in+OFF" peeks the player's input
# controller (dinput_pad.c): +0x2c8 steer (-1..1, + = left), +0x2d1 analog
# throttle byte, +0x2d4 throttle, +0x2dc brake, +0x2ec e-brake (0..1).
# [0x865658+id] is the game's latest value of joy event id on port 0
# (0x580d51): 0x90 STEER_ANALOG, 0x7d CAMERA_POV_CHANGE, 0x7e LOOKBACK,
# 0xa3 NITRO_BOOST.
