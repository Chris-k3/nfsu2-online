# Free-roam multiplayer with a virtual Windows friend: this instance runs the
# Windows plugin NFSU2FreeRoam.asi under Unicorn (out/nfsu2_asipeer,
# NFSU2_ROAM_ASI), not the Mac build's game side.  New career -> prologue free
# roam, wait until the other player's car is shown (an inert car outside the
# parking spot: "roam asi waitcars"), frame dumps from where the player
# stands, then behind the friend's car every few seconds.
0     tapuntil RETURN MC_Background.fng 120 4000
+120  tap LEFT
+30   tap RETURN
+240  tap BACK
+8    tap BACK
+8    tap BACK
+8    tap BACK
+20   type ${ROAM_PROFILE}
+60   tap RETURN
+240  tap RETURN
+0    waitfng GarageMain.fng 3000
+300  tap LEFT
+60   tap RETURN                      # Career
+300  tap RETURN                      # Start New Career
+0    waitfng UI_EngageMessageDialog.fng 8000
+120  tap RETURN                      # SMS: Continue
+0    roam waitroam 3000
+0    roam smsauto on
+0    roam asi waitcars 1 6000
+0    roam asi status
+30   dump w_here0
+120  dump w_here1
+120  dump w_here2
+0    roam asi follow 0 9
+45   dump w_follow1
+0    roam asi status
+45   dump w_follow1b
+300  roam asi follow 0 9
+45   dump w_follow2
+0    roam asi status
+45   dump w_follow2b
+300  roam asi follow 0 12
+45   dump w_follow3
+0    roam asi status
+45   dump w_follow3b
+600  roam asi status
+${ROAM_WATCH_FRAMES} roam asi status
+10   quit
