# Multiplayer races from free roam: a lobby on the world map.  A player opens
# a lobby at a multiplayer-only spot (Enter) and opens the world map: the
# lobby's icon, the game's own of its race's type, and its label beside it.
#   NFSU2_SAVE_SEED=<save tree> node web/tools/run-suite.mjs --base <server> --script mprace_map.txt
#        --marker "MAP DONE" --net Map --env NFSU2_ROAM=1 --env NFSU2_ROAM_WEBTEST=vlan --env NFSU2_ROAM_ROOM=<r>
#        --env MP_RACE=S2_SPRINT_3
0     bot on
+0    waitroam 6000
+0    bot off
+0    roam smsauto on
+0    careergo ${MP_RACE}
+300  roam mp spots 1
+0    tap RETURN                      # a lobby
+60   roam mp lobby
+600  tap M                           # the world map (the first M of a while is ignored)
+90   tap M
+300  dump map
+0    roam mp map strings
+0    tap ESCAPE
+300  roam mp lobby
+0    log MAP DONE
+10   quit
