# Free roam at the new career's start among roam-crowd's players parked on and
# around it (roam-crowd --track with points 0 to 8.5 m from it): friends' cars
# within NFSU2_ROAM_SPAWN_M (5 m) of the start are not shown, the others are,
# and passable while the player stands on the start.  "mp status" lists each
# slot's car (shown or hidden, where) for the check; [status] has the frame time.
#   roam-crowd --n 62 --room R --track <a pose csv: L rows 10000 s apart, 0 to
#   8.5 m from 1695.3 -883.6 24.1>; roam-pair --solo --page play --a
#   Name:roam_spawn_hide.txt --env NFSU2_ROAM_ROOM=R --env ROAM_CROWD_CARS=32
#   --env NFSU2_ROAM_SPAWN_M=5 (roam-pair turns the rule off unless told)

+120  tap LEFT
+30   tap RETURN
+240  tap BACK
+8    tap BACK
+8    tap BACK
+8    tap BACK
+20   type ${ROAM_PROFILE}
+60   tap RETURN
+240  tap RETURN
+0    waitfng GarageMain.fng 3000
+300  tap LEFT
+60   tap RETURN                      # Career
+300  tap RETURN                      # Start New Career

+120  tap RETURN                      # SMS: Continue
+0    roam waitroam 3000
